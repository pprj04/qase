# Device Runtime layer audit (verified 2026-09-29, line refs re-checked)

Key facts for anyone building a Device Runtime layer on QASE-2.1:

- Execution: server/browserBridge.js `ensureContext` override (L380-436) is the single launch seam. Local: `chromium.launch` (L413) with SYNTHETIC_MEDIA_ARGS + `newContext(emulationOptions)` (L419-422). BrowserStack: `connectBrowserstack` via `chromium.connectOverCDP` (browserstackProvider.js L120-128). Mode from `resolveExecution()` (L87-114): needs env.executionProvider==='browserstack' + browserstackCapabilities + BROWSERSTACK_USERNAME/ACCESS_KEY; else 'emulated' (with reason in label); no env → 'default'.
- Environment → context wiring: browserBridge.js L59-67 — `execution = resolveExecution(session.environmentSnapshot)`; emulationOptions = environmentEmulationOptions(env) when emulated, else legacy `contextOptionsFor(deviceId, landscape)` (deviceProfiles.js, 8 profiles WITH userAgent). environmentEmulationOptions (browserstackProvider.js L62-78) = viewport + deviceScaleFactor + isMobile + hasTouch ONLY. No userAgent in the environment path. agent.js L515-519 passes device/deviceLandscape/environmentSnapshot into attachBrowserBridge.
- Permissions: NO context.grantPermissions anywhere. Only microphone via CDP `Browser.setPermission` (browserMedia.js setMicrophonePermission L54-77). No camera/geolocation. In BrowserStack mode syntheticMedia=false (browserBridge.js L395) so even mic testing is disabled remotely.
- Environment model: environments table (migration 015 L10-40): env_id/platform/device/os/browser/versions/device_type/screen_size/execution_provider ('browserstack'|'local', default 'browserstack')/is_real_device/active/browserstack_capabilities jsonb. +016: screen_resolution, orientation, description, device_model_slug FK. Capabilities built in environmentRepository.js capabilitiesFor L45-62 (mac: browserName/browserVersion/os 'OS X'/osVersion; iOS: +deviceName +realMobile true; safari omits browserVersion). All catalog envs get executionProvider:'browserstack' (environmentCatalog.js L520).
- Run model: qa_runs gains environment_id + environment_snapshot jsonb (015 L63-67), hydrated runRepository.js L458-459, inserted L638-658. Snapshot is frozen full env record at app.js-level run creation (app.js resolveEnvironmentForRun L61-72, inactive envs 422). NO execution_provider/per-artifact columns on runs. Timing: TIMING_COLUMNS (runRepository L236-237) incl setup_started/setup_ended (store.js markExecutionStarted L410).
- Evidence: NO persisted screenshots. Frames are ephemeral SSE JPEG (EPHEMERAL set store.js L300; captureFrame browserBridge.js L905-933 carries base64/mimeType/url/title/loading/viewport/ts). qa_findings evidence is text (runRepository L501, L422). Crash snapshots .qase/runsnapshots/*.json.
- Catalog: environmentCatalog.js emulation = viewport/deviceScaleFactor/isMobile/hasTouch (iphone() L313-326, androidDevice() L219-231, windowsDevice L236-243, mac L347-353). device_models (016 L41-54): browserstack_device_name, screen_size ('6.3 inch'), screen_resolution ('WxH' derived from emulation viewport — NOT physical px despite comment), is_real_device, hardware_id. hardware table = chip display names only. NO DPR column, NO user_agent, NO permission capability data anywhere in DB. deviceProfiles.js (legacy) is the only place with real UA strings.
- UI: run list pill app.js L345-353 shows device·browser + provider in title tooltip. run-env-block renderRunEnvBlock app.js L3832-3859 (test case + environment + batch count). deviceDrawer chipLabel deviceDrawer.js L54-59 = device — os version — browser version (no provider). app.js L3408/3419 raw JSON dump of capabilities. createQaRun app.js L615-617 sends device/deviceLandscape/environmentId.
- Env vars: BROWSERSTACK_USERNAME, BROWSERSTACK_ACCESS_KEY (browserstackProvider.js L29-34, both required else fallback), QASE_RUN_STORE (local|postgres), QASE_EXECUTION_MODE (local|distributed, serviceFactory.js L23-25), CLEANSLATE_BROWSER_HEADLESS, CLEANSLATE_BROWSER_EXECUTABLE, QASE_FRAME_INTERVAL_MS/QUALITY, QASE_CURSOR_DWELL_MS, QASE_NAV_SETTLE_MS, QASE_WORKER_LEASE_MS/POLL_MS, QASE_REDIS_URL.
- Queue: qa_execution_jobs (005) with leases; worker.js + distributedExecution.js. Gaps for Device Runtime: no DPR/UA persisted, no permission config, no evidence artifacts, BrowserStack mode disables synthetic media & network policy install is attempted on remote context (browserBridge L396).
