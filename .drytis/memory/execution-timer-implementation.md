# Test Execution Timer — implementation map (MANOJ branch, Sep 2026)

Server-authoritative timing for QASE test runs. All timestamps live in `session.*` and `qa_runs` columns; the frontend never starts its own timer.

- `server/store.js` — `applyStatusTiming()`, `markReportPhase()`, `markExecutionStarted()`, `timingForEvent()` are the single source of timing truth. `setStatus()` calls `applyStatusTiming` + attaches `timing` (with `serverNow`) to the emitted status event. `listSessions()` summaries now carry `startedAt/completedAt/durationSeconds` (live elapsed for running runs).
- `server/agent.js` — `markReportPhase('start')` in `beginActivity` when the finalizer tool opens; `markExecutionStarted()` after first successful tool call; `markReportPhase('end')` in `completeRun()` before status done. Statuses: done=completed, error/interrupted=failed, idle-after-running=cancelled (write-once `completedAt`).
- Migration `013_run_timing.sql` — new columns queued_at, setup/report/cancelled timestamps, failure_reason; backfills completed_at=updated_at for stale terminal runs. COALESCE write-once updates in `runRepository.save()`.
- API: `GET /api/sessions/:id` returns `serverNow`; `GET /api/analytics/durations[?targetUrl=]`; `GET /api/analytics/targets/durations?targetUrl=` (400 without param). Both fall back to in-memory-store implementations in `localServices.js` (`durationAnalytics`/`targetDurationHistory` on the runStore) and to empty aggregates if the repo lacks them (e.g. `postgresServices.js` guards `typeof repository.x !== 'function'`).
- Frontend: `public/app.js` timer block — `noteServerNow(skew)`, `elapsedSecondsOf()`, `updateRunTimer()`, single shared `setInterval` (`startTimerInterval` in boot). SSE `status` events update session timing fields; snapshots too. Header pill `#run-timer` (states running/paused/completed/failed/cancelled). Run list rows show ⏱ duration; Performance panel (`#perf-panel`) + same-target comparison (`#perf-compare`), refreshed on selectSession and non-running status events.
- Tests: `server/runTiming.test.js` (timing helpers), `server/runTimingApi.test.js` (endpoints; service contract requires runs.create/delete/commit/etc + access.mount(app) shape).
- E2E harness pattern for this app: `createApplication({ services, tenantContext, authRequired: false })`, requests need `origin` header matching, sessions must be fetched inside `runWithRequestActor(ACTOR, ...)`. Full suite green: 419 tests / 412 pass / 7 skipped (keepalive + drytisTransport tests are occasionally flaky under full-parallel runs but pass individually).
